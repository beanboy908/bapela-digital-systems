# Bapela Digital Systems

The website source for **Bapela Digital Systems**, a digital-services agency focused on custom web infrastructure, automation, and business systems.

**Live site:** <https://bapeladigital.co.za>

## Overview

This repository contains the agency’s responsive marketing website. The site communicates the agency’s services, packages, case studies, and enquiry path for South African small and medium-sized businesses.

## Key capabilities

- Service and package information to help prospective clients identify suitable solutions.
- WhatsApp-based enquiry flow for direct client conversations.
- Case-study content that demonstrates delivered business solutions.
- Responsive, mobile-first layout designed for a range of screen sizes and network conditions.

## Run locally

Clone the repository and open `index.html` in a modern browser. The current site is a static HTML project and does not require a build step.
