# Blink & Blush by Theo

A dreamy, mobile-first booking site for Theo's cluster-lash service in Solomon Mahlangu Annex. The customer journey is intentionally short: choose a service, enter a preferred appointment time, and continue straight into a pre-filled WhatsApp message to **076 620 2796**.

## Exact flyer details preserved

- BYO lashes: **R50**
- My lashes: **R80**
- Location: **Solomon Mahlangu Annex**
- Booking: **WhatsApp 076 620 2796**

The supplied flyer is reused as the hero artwork from managed project storage. The footer credits Bapela Digital Systems and links back to the main Bapela footprint.
